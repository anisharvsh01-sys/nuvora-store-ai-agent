
# Nuvora Store AI Agent

Nuvora Store AI Agent is a virtual store assistant built with Jotform AI Agent Builder. It answers customer questions about products, delivery, and returns instantly, any time of day, in a friendly and professional tone.

## About
Online shoppers often have questions about products, orders, and policies. This agent acts as the first point of contact for store visitors, giving quick and consistent answers so customers don't have to wait for a human representative.

## Features
- Answers product and store-related questions
- Understands questions written in natural language
- Responds instantly, 24/7
- Friendly, conversational tone that matches the store

## Tools Used
- Jotform AI Agent Builder
- Prompt design and knowledge-base setup
